# 数据库配置

OpenDeepWiki 支持两个数据库后端：**PostgreSQL** 和 **SQLite**。项目根目录的 `compose.yaml` 默认启动 PostgreSQL。

## PostgreSQL（Docker 默认）

`compose.yaml` 已包含 PostgreSQL 服务，无需额外编排文件：

```yaml title="compose.yaml"
services:
  postgres:
    image: postgres:16-alpine
    restart: unless-stopped
    environment:
      - POSTGRES_DB=opendeepwiki
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=opendeepwiki123
    volumes:
      - postgres-data:/var/lib/postgresql/data

  opendeepwiki:
    environment:
      - Database__Type=postgresql
      - ConnectionStrings__Default=Host=postgres;Port=5432;Database=opendeepwiki;Username=postgres;Password=opendeepwiki123
    depends_on:
      - postgres

volumes:
  postgres-data:
```

### 外部 PostgreSQL

连接到现有的 PostgreSQL 实例：

```yaml title="compose.yaml"
environment:
  - Database__Type=postgresql
  - ConnectionStrings__Default=Host=your-db-host;Port=5432;Database=opendeepwiki;Username=your-user;Password=your-password
```

### 连接字符串格式

PostgreSQL 连接字符串遵循标准 Npgsql 格式：

```
Host=<host>;Port=<port>;Database=<database>;Username=<user>;Password=<password>
```

| 参数 | 默认值 | 描述 |
|---|---|---|
| `Host` | — | 数据库服务器主机名或 IP |
| `Port` | `5432` | PostgreSQL 端口 |
| `Database` | — | 数据库名称 |
| `Username` | — | 数据库用户 |
| `Password` | — | 数据库密码 |

### 何时使用 PostgreSQL

- 生产部署
- 高并发或大规模使用
- 需要强大的备份和复制
- 多实例部署

## 数据库初始化

OpenDeepWiki 在启动时自动运行数据库迁移。无需手动迁移步骤 — 应用在首次启动时创建所有必要的表和架构。

<Callout type="info">
  数据库迁移通过启动期间的 `DbInitializer.InitializeAsync()` 自动应用。这对 SQLite 和 PostgreSQL 都适用。
</Callout>

## 切换数据库

从 SQLite 迁移到 PostgreSQL：

1. 设置 PostgreSQL 实例
2. 在环境中更新 `DB_TYPE` 和 `CONNECTION_STRING`
3. 重启应用 — 架构将自动创建
4. 重新提交仓库以重新生成文档

<Callout type="warn">
  SQLite 和 PostgreSQL 之间没有内置的数据迁移工具。切换数据库需要从仓库重新生成文档。
</Callout>

## SQLite（本地可选）

非 Docker 本地运行仍可使用 SQLite。数据库文件会在首次运行时自动创建。

```yaml
environment:
  - Database__Type=sqlite
  - ConnectionStrings__Default=Data Source=opendeepwiki.db
```

### 何时使用 SQLite

- 开发和测试
- 小规模单实例运行
- 快速设置，基础设施最少

## 配置参考

| 变量 | 值 | 默认值 | 描述 |
|---|---|---|---|
| `Database__Type` | `sqlite`、`postgresql` | `postgresql` in Docker | 数据库后端类型 |
| `ConnectionStrings__Default` | 连接字符串 | Compose 中指向 `postgres` 服务 | 数据库连接字符串 |

数据库类型也可以通过 `appsettings.json` 设置：

```json title="appsettings.json"
{
  "Database": {
    "Type": "sqlite"
  },
  "ConnectionStrings": {
    "Default": "Data Source=/data/opendeepwiki.db"
  }
}
```

环境变量优先于 `appsettings.json` 值。
